# 08 · 快捷指令：双击背面，半屏解析

目标：在任何 App 里选中文字 → 复制 → **双击手机背面两下** → Fathom 从底部弹出半屏，自动开始解析。

不用先解锁找 App，也不用手动点分享。

---

## 一、先在「快捷指令」里建一个动作

只做一次。

1. 打开 **快捷指令** App（系统自带，图标是彩色方块叠在一起）
2. 点右上角 **+**，得到一张空的快捷指令
3. 点 **添加操作**，在搜索框输入 `获取剪贴板`，选中 **获取剪贴板**
4. 再点 **+ → 添加操作**，搜索 `URL`，选 **URL**
5. 在这个 URL 操作里填：

   ```
   fathom://analyze?text=
   ```

   然后把光标停在 `=` 后面，点键盘上方弹出的 **变量**，选 **剪贴板**（上一步的结果）。
   最后看起来是：`fathom://analyze?text=剪贴板`

6. 再加一个操作：搜索 `打开 URL`，选 **打开 URL**，它的参数会自动接上一步的 URL
7. 点右下角 **▶︎** 试运行一次 —— 应该直接跳到 Fathom，并且弹出半屏开始解析
8. 成功就点 **完成**，把快捷指令命名为 **Fathom 解析**（名字随便，等下要认它）

> 为什么要把文字放进链接里？这样 App 不用去读剪贴板，iOS 就不会弹「允许粘贴」的确认框。少一次点击。

---

## 二、绑到「轻点背面」

1. 打开 **设置**
2. **辅助功能** → **触控** → 拉到最底 **轻点背面**
3. 选 **轻点两下**
4. 在列表里找到 **Fathom 解析**，选中

绑好之后，在任何界面双击背面两下，效果就等于你手动运行那个快捷指令。

---

## 三、日常怎么用

```
选不认识的句子 → 拷贝 → 双击背面 → 半屏弹出并自动解析 → 看完往下滑或点 ✕ 收起
```

- 弹出的是**半屏卡片**，往上拖可以变成全屏看讲解
- 结果照旧自动进生词本
- 想直接切「单词 / 整句」：半屏里上方有分段控件，不用重新复制

> **小提示**：如果双击背面没反应，多半是手机壳太厚或者手tap的部位太靠上。敲手机背面**中间偏上**的位置，力度像敲门。

---

## 四、如果剪贴板里是「保存链接」

少见的兜底情况（免费签名拿不到 App Group 时才会出现）：扩展会把一条 `fathom://save?data=…` 塞进剪贴板。

用这个快捷指令跑一下也照样能存进生词本 —— App 会先认出这是回传结果，直接落库，不会再解析一次。

---

## 五、更简单的替代方案（一步版）

不想建两步？只加一个 **打开 URL** 操作，URL 填：

```
fathom://analyze
```

不带 `text` 时，App 会自己去读剪贴板。缺点是 iOS 会弹一次 **「Fathom 想粘贴…」**，需要点「允许粘贴」。

如果你不介意多这一次点击，这个版本最快。

---

## 六、链接都支持什么

| 链接 | 作用 |
| --- | --- |
| `fathom://analyze` | 解析剪贴板里的文字，自动判断单词还是句子 |
| `fathom://analyze?text=hello` | 解析指定的文字 |
| `fathom://analyze?text=…&mode=word` | 强制当单词解析 |
| `fathom://analyze?text=…&mode=sentence` | 强制当整句解析 |
| `fathom://add?text=…` | 和 analyze 一样，只是语义上表示「存进生词本」 |

文字里有空格、标点没问题：快捷指令会自动把它编码进链接。

---

## 七、还可以挂在哪

同一个快捷指令，除了「轻点背面」，还能挂到：

- **主屏幕图标**（快捷指令 → 长按 → 添加到主屏幕）
- **锁屏小组件**
- **Siri**：直接说「Fathom 解析」
- **分享表单**：快捷指令的「详细信息」里打开「在共享表单中显示」，就不用先拷贝了

---

## 八、常见问题

**Q：双击背面没反应。**
A：设置 → 辅助功能 → 触控 → 轻点背面，确认选的是「轻点两下」并且绑定的是 `Fathom 解析`。仍不行就重启一次手机，iOS 偶尔会丢绑定。

**Q：跳到 Fathom 了，但半屏是空的。**
A：说明剪贴板里没有文字。先选中文字、点「拷贝」，再双击背面。

**Q：提示「无法打开 URL」。**
A：Fathom 被卸载或被 AltStore 覆盖安装过，URL scheme 需要 App 至少打开过一次才注册。手动打开一次 App 再试。

**Q：能不能「选中就直接弹」，不用拷贝？**
A：不能。iOS 不允许第三方读别的 App 里的选区文字。拷贝、分享、快捷指令是仅有的三条路。
