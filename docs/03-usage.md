# 03 · 使用说明

---

## 一、先拿到 DeepSeek 的 API Key

1. 打开 <https://platform.deepseek.com/> → 注册（手机号或邮箱都行）
2. 登录后进 **充值**，充 **10 元**（够查几千次，具体见 [费用](04-engines-and-cost.md)）
3. 左侧 **API keys** → **创建 API key** → 名字随便填 `fathom`
4. 复制那串 `sk-` 开头的字符

> ⚠️ Key 只显示一次，关掉页面就看不到了。丢了就再建一个。

---

## 二、在 App 里填 Key

1. 打开 **Fathom** → 底部 **设置**
2. **服务商** 选 `DeepSeek`
3. **API Key** 粘贴刚才那串
4. **模型** 留空即可（默认就是 `deepseek-flash`，速度快、便宜）
5. 点 **测试连接** → 显示「连接正常」就成功了
   - 报 401：Key 贴错了或多了空格
   - 报 402：账户余额不足
   - 报网络错误：检查代理/网络，或者先把「Base URL」留空用默认值

> 第一次在**分享菜单扩展**里使用时，如果扩展读不到主 App 的配置（免费账号常见），
> 它会弹出一个小界面让你再填一次 Key。填完存的是扩展自己的一份，之后不用再填。

## 三、在别的 App 里划词

### Apple Books / Safari / 备忘录 / 邮件 / PDF

1. 长按选中一个单词或一句话（拖两端的小圆点可以扩选）
2. 弹出菜单里点 **分享**（Safari 选中文字后可能在「拷贝 / 查询」里，点向右箭头）
3. 分享面板里找 **Fathom**（第一次要点「更多 → 编辑操作」打开开关）
4. 半屏卡片弹出，2–4 秒后出结果：

   - 单词 → 音标 / 词性 / 释义 / 搭配 / 例句 / 辨析 / 记忆钩子
   - 句子 → 译文 / 主谓宾 / 从句 / 难点词 / 语法点 / 难度

5. 底部三个按钮：**复制结果**、**重新解析**、**存入生词本**
6. 点右上角 ✕ 关闭，回到原来的阅读位置（不会打断你）

### 看不懂？点「讲深一点」

结果下面有一条 **讲深一点** 的按钮（整句才有）。点它会再发一次请求，写一节小课，固定六个部分（某一节没内容会自己省掉）：

1. **这句话什么意思** —— 一两句人话译文
2. **拆开看** —— 只挑 1–3 个中国人容易读错或读漏的地方，讲为什么这么用、最容易误解成什么
3. **结构** —— 一张小表：英语部分 / 作用 / 中文意思，最后点出规律
4. **母语者怎么想** —— 潜台词、说话人的态度，或者中英表达习惯的差别
5. **为什么长这样** —— 语法：为什么这里用 `-s` / `-ed` / `-ing` / `have been` / `being` / 被动 / 比较级，先说「换成别的会变什么意思」，再说「美国小孩是怎么理解它的」，不背规则
6. **能直接套用** —— 2 条能立刻用出去的例句

慢一些（10–30 秒），但讲得透；右上角可以一键复制整节课。

> 卡片是「看懂」，讲深一点是「学会」。日常查词用卡片就够，
> 碰到真正想弄明白的句子，再点它。

> **如果点了「存入生词本」却没跳回 App**：极少见，通常是宿主不允许扩展唤起别的 App。
> 这时扩展会自动把一条「保存链接」放进剪贴板并弹提示——回到 Fathom，
> 在**生词本**页点左上角的**剪贴板图标**，这条结果就直接入册（不用重新解析、不再花一次请求）。
> 在「解析」页点**粘贴**也一样能识别。

### X（Twitter）

X 的分享菜单一般只提供「帖子链接」，给不到你选中的文字，所以：

- 在 X 里长按选中 → **拷贝**
- 打开 Fathom → **解析** 标签 → 点 **粘贴** → 开始解析
- 或者：在 Fathom 生词本页面点左上角**剪贴板图标**，直接解析当前剪贴板

### 解析类型自动判断

- 1 个词、或 2–3 个词且没有句号问号 → 按**单词**解析
- 更长、或带句末标点 → 按**句子**解析
- 判断错了？结果页上方的分段控件随时切换，会自动重新解析

## 四、生词本

- **自动保存**：每次解析成功都会自动进生词本（30 秒内重复查同一个词只存一条）
- 列表：显示词头/原句、类型、释义摘要、时间；支持搜索
- 点进去：看完整解析、复制、**重新解析**（换了模型想再查一次）、删除
- 右上角菜单：**导出 CSV** / **导出 Anki** / 清空

### 导出怎么用

| 格式 | 用途 | 怎么导入 |
| --- | --- | --- |
| **CSV** | Excel / Numbers / 直接看 | 用 Excel 打开（UTF-8 带 BOM，中文不乱码） |
| **Anki** | 做记忆卡 | 电脑版 Anki → 文件 → 导入 → 选文件 → 字段分隔符选 **Tab**，勾「允许 HTML」 |

Anki 文件已经写好了 `#separator:tab`、`#html:true`、`#tags column:3`，
正面是单词/原句，背面是音标+释义+搭配+例句+语法，标签是 `fathom`。

导出后是系统分享面板，可以存到「文件」、发微信、或 AirDrop 到电脑。

## 五、离线兜底

设置里有 **离线兜底翻译** 开关（默认开）。它的作用：

- 网络请求失败时，结果页底部会出现一个「离线翻译」区块
- 用的是苹果自带的翻译（**在本机完成，不上传**，且完全免费）

前提是系统里已经装了英中语言包：第一次使用时按提示下载（约 100 MB），
或到 设置 → 通用 → 语言与地区 → 翻译语言 里添加「英语 → 简体中文」。

> 离线只能给译文，没有语法解析和搭配。它是「断网时不至于什么都看不到」的保险，不是主力。

## 六、换别的模型（可选）

设置 → 服务商，可以切到：

- **OpenAI（ChatGPT 接口）**：默认 `gpt-5-mini`，解析质量好，按量计费比 DeepSeek 贵
- **Anthropic**：Claude，长句语法讲解细腻，价格最高
- **OpenAI 兼容**：任何兼容 `/chat/completions` 的服务（Ollama 本地、硅基流动、月之暗面、通义等），
  自己填 Base URL 和模型名
- **DeepL**：只翻译、不做语法解析，质量好但功能单一

> **注意：ChatGPT 的免费版没有 API。** 网页/App 里的免费对话额度不能给第三方程序调用。
> 想用 OpenAI，得去 `platform.openai.com` 单独开 API 计费账号并充值（最低 5 美元），
> 拿到的 Key 形如 `sk-…`，填进设置里即可。

改完记得点 **测试连接**。想切回默认：设置里把「模型」「Base URL」清空即可。

### 模型名报错（HTTP 400 / 404）怎么办

模型名是各家自己起的，改了名字旧名就会失效。设置页「进阶」里那行小字写着当前服务商的常用名字：

- DeepSeek：`deepseek-flash`（快、便宜）、`deepseek-v4-pro`（更强）
- OpenAI：`gpt-5-mini`、`gpt-5`
- Claude：`claude-sonnet-4-5`、`claude-haiku-4-5`

把「模型」一栏直接改成新的名字，再点测试连接。实在不知道就填服务商文档里最新的那个。
