# 07 · 常见问题（装之前想知道的那些事）

## 1. 一定要用 GitHub 吗？有没有更省事的办法？

看你的条件：

| 路线 | 你需要有什么 | 时间 | 花费 | 适合 |
| --- | --- | --- | --- | --- |
| **本项目：GitHub 云端编译 + AltStore** | Windows 电脑 + 免费 Apple ID | 首次约 45 分钟 | 0 元 | **你现在的情况** |
| 借一台 Mac 用 Xcode 直接装 | 一台别人的 Mac（10 分钟） | 约 20 分钟 | 0 元 | 有 Mac 的朋友 |
| TestFlight | 99 美元/年 Apple 开发者账号 | 约 30 分钟 | ￥688/年 | 想一次装一年、或给朋友用 |
| 上架 App Store | 99 美元/年 + 审核 | 几天 | ￥688/年 | 想公开卖/分享 |

有 Mac 的话其实更简单，工程里备了一个脚本：

```bash
bash scripts/build-mac.sh
```

它会自动装 XcodeGen、生成 `Fathom.xcodeproj` 并用 Xcode 打开。然后在 Xcode 里
选自己的免费 Team（"Personal Team"）、连上 iPhone、按 ⌘R 就装好了。**这条路不需要 AltStore**，
而且免费账号在 Xcode 里签名时，App Group 往往也能正常申请到。

---

## 2. 为什么免费账号只有 7 天？

这是苹果的限制，不是本项目的问题：免费签名用的证书有效期就是 7 天，
到期后 App 打不开，续签一次即可（数据不丢）。付费账号（￥688/年）是 1 年。

---

## 3. 能不能给朋友也装一个？

- 免费账号：**不能**。签名和你的 Apple ID、你的设备绑定，别人的手机装不上。
- 想让朋友用：让对方按本项目自己走一遍（各用各的 Apple ID），或者你买开发者账号走 TestFlight 发邀请。

---

## 4. 用免费账号自签，会不会封号？

自签安装到**你自己的设备**是苹果允许的行为（Xcode 免费账号就是为这个准备的），
正常使用不会封号。要注意的只有两条：

- 不要用别人的 Apple ID 登录签名工具；
- 不要把带你自己签名的 IPA 发给别人装。

---

## 5. 我的数据存在哪？会上传吗？

- **生词本**：一个 `vocabulary.json` 文件，存在 App 自己的沙盒里（有 App Group 时在共享容器）。
- **API Key**：存在 App 的本地偏好设置里，只有调用 API 时才会随请求发给你选的服务商（如 DeepSeek）。
- 除了「你选的那家 AI 服务商」，没有任何第三方服务器，作者也收不到你的数据。
- 想彻底清掉：删 App 即可。

---

## 6. 换手机 / 重装系统，生词本会丢吗？

会。数据在手机上，不在云端。所以：

- 定期在 App 里**导出 CSV 或 Anki** 存到电脑/网盘；
- 重新装好 App 后，CSV 可以再导入 Excel；Anki 卡片直接导入 Anki。

（如果你愿意，也可以自己加 iCloud 同步——见 [06 二次开发](06-development.md)。）

---

## 7. 能装在 iPad 上吗？

能，但要改一行配置：`project.yml` 里两个 target 的 `TARGETED_DEVICE_FAMILY: "1"` 改成 `"1,2"`，
然后重新跑一次 GitHub Actions。iPhone 端的安装流程完全一样。
（本项目的界面是按 iPhone 竖屏排的，iPad 上会显示成放大的手机界面。）

---

## 8. 能在 Mac 上用吗？

不能直接用（Mac 版需要 Catalyst 或原生 AppKit，是另一套工作）。但 Mac 上的「划词」需求，
更省事的做法是用现成的浏览器插件 + DeepSeek 网页版。

---

## 9. 我不想用 DeepSeek，能用 ChatGPT 或 DeepL 吗？

能，App 的设置页里可以切：

- **OpenAI / Claude**：效果略好，但国内需要代理，且按美元计费（见 [04 引擎与费用](04-engines-and-cost.md)）。
- **DeepL**：只能翻译，给不了语法结构分析，不适合本项目的「长难句拆解」。
- **自建/兼容服务**（Ollama、LM Studio、Kimi、通义）：把 Base URL 填成兼容 OpenAI 的 `/v1` 地址即可。

---

## 10. 解析结果不准 / 太长 / 太短，怎么办？

解析质量几乎完全取决于**提示词**。三条改法（都在 [06 二次开发](06-development.md) 里有细节）：

1. 换更强的模型：设置里把模型改成 `deepseek-v4-pro`；
2. 改 `Shared/Services/PromptBuilder.swift` 里的 `systemMessage` 和 `extra`；
3. 加 `sourceHint`：告诉模型这段话出自文学/论文/新闻，解释风格会跟着变。

---

## 11. 分享菜单里一直没有 Fathom

1. 先在 Safari 里选中文字试一次（Books 的分享面板条目更少）；
2. 分享面板 → **更多** → **编辑操作** → 在「操作」分组里打开 Fathom；
3. 还不行：删掉 App 重装一次（扩展注册有时会被系统缓存卡住）。

---

## 12. 这个项目以后还能改吗？

能。所有「你可能想改的东西」都集中在少数几个文件里，`docs/06-development.md` 开头有一张对照表：
改名字、改图标、改提示词、换模型、加语言、加同步，各自对应哪个文件、改哪几行。
