# 04 · 引擎与费用

> 结论先放这儿：**日常用 DeepSeek `deepseek-flash`**——便宜到可以忽略、中文语法讲解够专业、国内直连不用折腾。
> 想要「不花钱 + 断网也能译」就开离线兜底（苹果原生翻译）。追求极致讲解质量再考虑 Claude。

## 二、DeepSeek 具体账本

模型 `deepseek-flash`（官方现价，元 / 百万 tokens）：

| | 缓存命中输入 | 缓存未命中输入 | 输出 |
| --- | --- | --- | --- |
| 空闲时段 | 0.02 | 1 | 4 |
| 高峰时段 | 0.04 | 2 | 8 |

高峰 = 北京时间 **周一至周五 9:00–12:00、14:00–18:00**（法定节假日除外），其余时间半价。

**实际一次划词的成本**（按 800 输入 + 500 输出估算，空闲时段）：

```
输入 800 × 1 / 1,000,000  = 0.0008 元
输出 500 × 4 / 1,000,000  = 0.0020 元
合计                        ≈ 0.0028 元  ≈ 0.3 分钱
```

所以：

- **10 元 ≈ 3000–4000 次查询**（按句子算；单词更便宜）
- 每天查 20 次，**一个月不到 2 元**
- 提示词固定，命中缓存后输入部分几乎免费，实际还能再便宜一截

> 桌面端 chat.deepseek.com 是免费的，本 App 走 API 才计费（因为要稳定的结构化 JSON 输出）。

## 三、各方案的真实差异（选型理由）

### DeepSeek flash —— 主力
- **快**：默认开思考模式会很慢，本项目已在请求里显式关闭（`thinking: disabled`），实测 2–4 秒出结果
- **会讲语法**：能稳定给出「主语/谓语/宾语/定语从句/非谓语」这种中文标注，不是干巴巴的翻译
- **便宜**：比一杯奶茶便宜两个数量级
- **JSON 稳定**：支持 JSON Output，配合三层容错，几乎不会解析失败

### OpenAI / Claude —— 什么时候值得
- 遇到**文学性很强**的句子（隐喻、双关、倒装 + 省略），Claude 的讲解更细
- 你在国内已经有稳定的代理和 OpenAI/Claude 额度
- 代价是成本高一个数量级，且网络不稳时体验差

### DeepL —— 只当翻译器
- 译文自然、术语准，但**没有任何语法结构**，单词也不给音标搭配
- 适合「我只要一句人话翻译」的场景；本项目里它只填译文一个字段

### 苹果原生 Translation —— 免费保险
- iOS 18 起提供，**在本机跑**，不联网、不上传、不要钱
- 只有整句译文，没有语法分析；单词脱离语境时译得比较粗
- 本项目把它做成「离线兜底」：主服务失败时补一个译文区块
- 语言包需要先下载（约 100 MB），扩展里无法弹下载框，所以要在主 App 里触发一次

---

## 四、为什么不用「免费的网页翻译接口」

- 逆向接口随时失效，且拿不到结构化的语法解析
- 请求频繁会被封 IP，你的 Key 也可能被风控
- 隐私：把整段阅读内容发给不明第三方

本项目所有请求都发往**你自己配置的服务商**，Key 存在手机本地，代码里没有任何统计上报。

---

## 五、想省钱可以这么调

1. **高峰时段用单词模式**：单词输出短，成本约为句子的 1/2
2. **句子上限**：App 会把超长文本截到 1200 字符，避免一次贴一整页
3. **别开重复查询**：生词本会自动去重（30 秒内同一个词只存一条），但「重新解析」按钮会真的再请求一次
4. 设置里把**模型**改成 `deepseek-flash`（默认值），别填 `deepseek-v4-pro`——后者贵 5 倍以上，划词场景用不上
